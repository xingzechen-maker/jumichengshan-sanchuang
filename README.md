# 聚「猕」成山 · 三创赛项目档案

> 绿色生态与智慧营销的舌尖「堰」遇 —— 都江堰红心猕猴桃品牌升级与全链路运营方案

全国大学生创新创业大赛（三创赛）· 三农赛道 · 四川赛区 · 团队 ID 745411
首次参赛 · 四川农业大学 · 2024.10 – 2025.06

---

## 一、项目是什么

针对都江堰红心猕猴桃「品牌分散、辨识度弱、农产品附加值低、农文旅联动弱」四个产业痛点，
设计并验证了一套「农产品品牌 + 文创开发 + 文旅体验」融合的商业模式，
通过电商直播与全渠道营销把区域特色农产品推向市场。

**一句话**：不是卖一箱猕猴桃，是把都江堰猕猴桃做成一个能卖品牌溢价、带动农户增收的产业 IP。

---

## 二、核心工作与成果

### 模式创新

- **联动机制**：采用「博士站研究所 + 公司 + 基地 + 社区」四方联动模式，产学研销一体设计
- **双直播矩阵**：搭建产地溯源直播 + 校园场景直播，分别解决「产品信任」与「流量获取」两个不同问题
- **分层内容设计**：科普讲解型（信任背书）+ 沉浸式采摘型（体验驱动）双内容线
- **营销链路闭环**：公域引流 → 私域互动 → 交易转化，配合抽奖、限时秒杀、满减优惠玩法

### 运营实绩（截至2025年9月）

| 指标 | 数值 |
|---|---|
| 累计调研时长 | 500+ 小时 |
| 累计直播时长 | 199 小时 |
| 累计平台销售额 | 13,526 元 |
| 近三月累计订单数 | 1,020+ |
| 下单-支付转化率 | 超 60% |

### 保鲜技术（针对行业核心痛点）

针对猕猴桃储存难、易变质腐败的问题，提出组合解决方案：
纳米保鲜技术 + 气调保鲜技术（包装成本 0.8–1.5 元）+ 包装附带储存说明卡片。

### 产学研合作足迹

与 5 家单位建立合作（2024.08 – 2024.11）：

- 仙果寨红心猕猴桃基地（2024.08）
- 都江堰天赐猕源公司（2024.09）
- 都江堰猕猴桃协会（2024.10）
- 都江堰猕猴桃博士站（2024.10）
- 都江堰猕尚小金矿公司（2024.11）

技术层面联合博士站采用「3+3」攻关技术，即 3 个粮果 / 3 个蔬菜复合套作模式，
在耕地容积率、果实生育期、可溶性固形物含量等指标上做对比实验。

## 六、项目背景参考

项目立项依据四川省「十四五」推进农业农村现代化相关政策，
构建「10+3」现代农业体系，为都江堰红心猕猴桃产业提供政策保证与方向指引。
2023 年都江堰市猕猴桃种植规模已达 10 万亩。
